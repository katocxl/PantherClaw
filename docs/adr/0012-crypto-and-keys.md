# ADR-0012 — Standard-library cryptography and KeyProvider

**Status:** Accepted (2026-10-08)

**Decision.** Only Go standard-library primitives: Ed25519 (JWS via go-jose v4 with algorithm allowlists), optional ML-DSA-65 co-signatures, AES-256-GCM with random nonces for envelope encryption (per-org/per-purpose DEKs, AAD binding org/table/column/row), HPKE MLKEM768-X25519 for sealed credentials (AAD binds org/connection/version/hosts; broker key per tenant or gateway deployment), TLS 1.3 with hybrid post-quantum key exchange, SHA-256/HMAC. KEKs come from a `KeyProvider` port: file (dev) → OpenBao Transit → cloud KMS. Offline roots (licence signing, package signing) are generated by `pclaw-admin` and never touch CI. FIPS build variant: `GOFIPS140=certified`.

**Consequences.** No third-party cryptography libraries; post-quantum readiness for confidentiality (X-Wing, ML-KEM) and a reserved slot for PQ signatures. Go cannot reliably zeroize secrets (residual risk R-09).
