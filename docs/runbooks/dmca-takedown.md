# Runbook — Licence or trademark violation (DMCA takedown)

1. **Confirm:** the copy contains PantherClaw code (canary `pcfp-37609359f35b52c36816`, unique identifiers, file headers) and is used/distributed in violation of the BSL terms (production beyond the Additional Use Grant, hosted/competing offering, removed notices) or uses the PantherClaw marks.
2. **Collect evidence:** URLs, commit SHAs, screenshots, archive.org snapshots, which licence terms are violated, dates.
3. **GitHub-hosted copies:** submit a DMCA takedown notice via GitHub's DMCA form (free). Include the original repository URL, the infringing URLs, the licence, and a good-faith statement.
4. **Other hosts / package registries:** use the host's copyright or trademark complaint process (npm, PyPI and container registries have reporting forms).
5. **Commercial violators:** send a licence-violation notice offering a commercial licence (COMMERCIAL_LICENSE.md); escalate to legal counsel if ignored.
6. **Record** the case privately (not in the public repo).
